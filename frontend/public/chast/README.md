# Покупка Частинами monobank

`chast-badge.svg` — оригінальний український `1-raw.svg` із комплекту
`monobank-pay-part-media-kit`, розділ `logos / paw+text / ua / svg`.
Завантажено 10.10.2026 без зміни векторів, кольорів та пропорцій.

## Джерело файлу

- [Медіакіт](https://drive.google.com/drive/folders/1mY02EZONrpNuaIaz64Q33hE_dJ1zDjKN)
- [Оригінальний SVG](https://drive.google.com/file/d/12p0rGoTkfw4OiCfKpge_4JHYwaqnh8ct/view)
- [Документація Platon із посиланням на медіакіт](https://platon.atlassian.net/wiki/spaces/docs/pages/1332281345)

Поточний гайд у Figma, на який посилається monobank, під час завантаження
повертав HTTP 403. Тому використано готовий файл із медіакіту, наданого
платіжним провайдером. Візуальну відповідність останній редакції Figma
не підтверджено.

## Правила оформлення

Звірено з офіційними сторінками 10.10.2026:

- [Маркетингові матеріали](https://monobank.ua/knowledge-base/chast/marketing)
- [Назва та бренд](https://monobank.ua/knowledge-base/chast/marketing/brand)

Не перемальовувати логотип і не змінювати його кольори. CSS масштабує ширину,
а висота рахується автоматично. Графічне написання збережене як у джерелі;
текстова назва в інтерфейсі — «Покупка Частинами monobank».

`ChastBadge` додає підпис банку та текстовий fallback на випадок помилки.
`ChastLegal` містить юридичні тексти про ставку, строк та реквізити банку.
Текст про ставку має бути не меншим за половину розміру назви сервісу.
