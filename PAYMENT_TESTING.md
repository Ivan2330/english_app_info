# Перевірки оплат — 11.10.2026

Тестові налаштування та токен збережені локально в `backend/.env.testing`.
Файл ігнорується Git. Не переносити його на продакшен і не публікувати токени.
Архів є копією попереднього конфігу й містить також бойові секрети в коментарях.
У production `.env` тестові значення прибрані; бойові ключі ПЧ із коментарів
активовані за вказівкою власника, `PAYMENTS_ENABLED=true`.
Помилковий старий коментар «plata не має пісочниці» видалено з production:
режим еквайрингу визначається токеном, адреса API для обох режимів однакова.

## Результати

- 24 автоматичні тести реальних обробників із SQLite та підставленим API банку пройшли.
- Збірка React/Vite пройшла.
- ПЧ на офіційній пісочниці: SUCCESS/ACTIVE, WAITING_FOR_CLIENT,
  EXCEEDED_SUM_LIMIT; WAITING_FOR_STORE_CONFIRM → confirm → SUCCESS/ACTIVE.
- Бойовий картковий токен: дані мерчанта Prime Academy та публічний ключ доступні.
  Неоплачений рахунок на 1 грн створений і деактивований; списань за ним не було.
- Окремий тестовий картковий токен: рахунок на 1 грн оплачений користувачем,
  API підтвердив success, 100 коп., UAH/980 і правильний reference.
- SQL міграції 0008_payment_refunds згенеровано успішно без підключення до БД.

Це не наскрізна перевірка розгорнутого сайту: тестовий картковий рахунок
створювався без запису замовлення в серверну БД. Доставка callback на новий
сервер, реальні списання/повернення та блокування у PostgreSQL не перевірені.
Після деплою потрібен один повний сценарій через checkout сайту.
Схвалення monobank ці перевірки не гарантують.
